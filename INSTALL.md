# Installation and Deployment Guide

Follow these instructions to configure, seed, and launch the MediBot application locally or inside Docker containers.

---

## Prerequisites

Ensure you have the following installed on your machine:
* **Node.js** (v18.0.0 or higher) & **npm** (v9.0.0 or higher)
* **Python** (v3.10 or higher) & **pip**
* **Docker** & **Docker Compose** (optional, for containerized deployment)
* **ngrok** (optional, for testing Twilio IVR calls locally)

---

## Environment Configuration

1. Copy the environment variables example file to create your active configuration:
   ```bash
   cp .env.example .env
   ```
2. Open `.env` and fill in the required keys:
   * `GEMINI_API_KEY`: Get a free key from Google AI Studio. If left blank, the system will fall back to **Mock AI Mode** (enabling symptom checking and dashboard testing without active keys!).
   * `TWILIO_ACCOUNT_SID`, `TWILIO_AUTH_TOKEN`, `TWILIO_PHONE_NUMBER`: Fill these in to test voice IVR calls.
   * `SMTP_HOST`, `SMTP_PORT`, `SMTP_USER`, `SMTP_PASSWORD`: Configure to enable email PDF report dispatches.

---

## Deployment Option 1: Local Setup

### 1. Backend Server Setup
1. Navigate to the backend directory:
   ```bash
   cd backend
   ```
2. Install Python packages:
   ```bash
   pip install -r requirements.txt
   ```
3. Run the database seeding script to instantiate tables and load test logs:
   ```bash
   python scripts/seed_data.py
   ```
4. Start the FastAPI development server:
   ```bash
   uvicorn app.main:app --reload --host 0.0.0.0 --port 8000
   ```
   The backend API documentation is now accessible at `http://localhost:8000/docs`.

### 2. Frontend React Setup
1. Open a new terminal and navigate to the frontend directory:
   ```bash
   cd frontend
   ```
2. Install Node modules:
   ```bash
   npm install
   ```
3. Start the Vite React development server:
   ```bash
   npm run dev
   ```
   Open `http://localhost:5173` in your browser to interact with MediBot.

---

## Deployment Option 2: Docker Compose (Production Ready)

To launch the entire stack (PostgreSQL, FastAPI backend, and Nginx-served React frontend) in a containerized environment:

1. Configure the `GEMINI_API_KEY` in the root `.env` file.
2. Build and launch the containers:
   ```bash
   docker-compose up --build
   ```
3. Access the services:
   * **Frontend Application:** `http://localhost:3000`
   * **Backend API Docs:** `http://localhost:8000/docs`
   * **PostgreSQL Server:** Port `5432`

## Testing Twilio IVR Webhooks Locally

To test the telephone dispatcher webhook without deploying to a cloud server:

1. Launch the local FastAPI backend on port `8000` (via Local Setup or Docker).
2. Start an HTTP tunnel using ngrok in a separate terminal:
   ```bash
   ngrok http 8000
   ```
3. Copy the secure forwarding URL generated by ngrok (e.g., `https://xxxx-xx-xx.ngrok-free.app`).
4. Log into your **Twilio Console**, select your active phone number, and locate the **Voice & Fax** configuration block.
5. In the **A Call Comes In** webhook field, paste your ngrok URL and append the IVR endpoint:
   ```text
   https://xxxx-xx-xx.ngrok-free.app/api/ivr/call
   ```
6. Set the HTTP request method to `POST`. Save configurations.
7. Dial your Twilio phone number. The server will intercept the call, play local audio guides, transcribe symptoms, query Gemini/RAG, and respond vocally.
